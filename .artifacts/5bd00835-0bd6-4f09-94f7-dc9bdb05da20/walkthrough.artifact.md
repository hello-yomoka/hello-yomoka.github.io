# ランダム再生の初期化ロジック改善完了

ランダム再生が選択されている際、1枚目のカードも完全にランダムに選ばれるように修正しました。

## 変更内容

### JS (Playerロジック)

#### [player.js](file:///C:/develop/hello-yomoka.github.io/js/player.js)

- **`initSequence` 関数の汎用化**:
    - 開始位置（`startIndex`）が指定されない（`null`）場合の挙動を追加しました。
    - ランダムモードかつ開始位置の指定がない場合、全リストを対象にシャッフルを行うようにしました。
- **呼び出し箇所の修正**:
    - **CSV読み込み時 (`applyCsv`)**: 固定の 0番目ではなく、現在の設定に従って初期化するようにしました。
    - **最初から読む時 (`restartPlayback`)**: 同様に、固定の 0番目ではなく完全に初期化し直すようにしました。

## 検証結果

### 動作確認
- [x] 「ランダム再生」設定時、CSV読み込み直後の1枚目がランダムに変わること。
- [x] 「ランダム再生」設定時、「最初から読む」ボタンを押すたびに1枚目が変わること。
- [x] 「順番に再生」設定時は、これまで通り常に最初のデータから始まること。

> [!TIP]
> 再生中に「ランダム再生」と「順番に再生」を切り替えた場合は、現在表示されているカードを起点に順序が作り直されます（現在のカードが中断されないようにするため）。
