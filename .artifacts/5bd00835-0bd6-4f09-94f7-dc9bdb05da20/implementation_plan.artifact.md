# ランダム再生の初期化ロジックの改善プラン

ランダム再生が選択されている場合、再生開始時（CSV読み込み直後や「最初から読む」ボタン押下時）に1枚目のカードもランダムに選ばれるように修正します。

## ユーザーレビューが必要な事項

> [!NOTE]
> 現在、ランダム再生を選択していても、再生開始時には必ずCSVの最初のデータ（2行目）が表示される仕様になっていました。これを修正し、最初から完全にランダムな順序で再生が始まるようにします。

## 提案される変更

### JS (Playerロジック)

#### [MODIFY] [player.js](file:///C:/develop/hello-yomoka.github.io/js/player.js)

`initSequence` 関数を、開始インデックスが指定されない場合に全データを対象にシャッフルするように変更します。また、`applyCsv` と `restartPlayback` からの呼び出しを、特定のインデックスを強制しない形式に更新します。

- `initSequence`: `startIndex` のデフォルトを `null` に変更し、`null` かつ `random` モードの場合は全リストをシャッフルするロジックを追加します。
- `applyCsv`: `initSequence(0)` を `initSequence()` に変更。
- `restartPlayback`: `initSequence(0)` を `initSequence()` に変更。

## 検証プラン

### 手動検証
1. 読み上げ順を「ランダム再生」に設定する。
2. サンプルCSVを読み込むか、「最初から読む」ボタンを押す。
3. 表示される1枚目のカードが、実行するたびに変わる（ランダムである）ことを確認する。
4. 読み上げ順を「順番に再生」に設定した場合、常に最初のデータから始まることも合わせて確認する。
